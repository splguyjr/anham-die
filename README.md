# AnhamDie

macOS 네이티브 투두 앱. 메뉴바에 상주하면서 **화면 맨 앞 플로팅 오버레이**와
**트리거 기반 브리핑 + Jira식 이월**로 하루를 관리한다. 알림(푸시)은 없다.
로컬 전용, 동기화 없음. macOS 15+. UI는 한국어.

## 설치 (Homebrew)

```bash
brew install splguyjr/tap/anhamdie
```

설치가 끝나면 **`/Applications/AnhamDie.app`에 자동 설치**된다 —
`open /Applications/AnhamDie.app`으로 실행하면 메뉴바에 상주한다.
업데이트는 `brew upgrade anhamdie`, 제거는 `brew uninstall anhamdie`(앱까지 함께 제거).

소스에서 로컬 빌드하는 cask라 1~2분 걸린다 (Command Line Tools 필요 — brew
사용자는 이미 있음). 로컬 빌드 산출물이라 Gatekeeper 격리/경고 없이 바로 실행된다.

## 기능 (v13)

- **색상 테마 (v5 → v7 심화)** — 설정 「테마」 탭에서 **프리셋 팔레트 9종**(기본 / 세피아 /
  포레스트 / 오션 / 라벤더 / 모노 / 하이콘트라스트 / 다크 / 미드나잇)을 고르고, 별도
  **강조색 ColorPicker**로 액센트를 직접 지정한다. 선택 즉시 앱 전역(메인·오버레이·
  브리핑·캘린더·퀵애드·메뉴바)에 실시간 반영. 모든 색이 "현재 테마"에서 해석되며
  (하드코딩 색 없음), 강조색은 비워 두면 팔레트 기본값을 쓴다. 팔레트·강조색은 저장·복원.
  D-day 색 규칙(지남/오늘/임박/여유)의 의미는 유지하되 테마 안에서 재정의된다.
  - **사용자 커스텀 테마 (v7)**: 갤러리에서 아무 테마나 **"복제해서 편집"** → 12색 슬롯
    (배경/표면/보조 표면/텍스트 3종/구분선/강조/D-day 4종) 각각 ColorPicker + 슬롯별 ↺
    리셋(베이스 프리셋 값), 이름 변경·복제·삭제·라이트/다크 토글. 편집 중 실시간 전역 반영,
    여러 개 저장(JSON 영속). 선택 중이던 커스텀 테마를 삭제하면 기본 프리셋으로 폴백.
  - **모노 = 진짜 무채색 (v7)**: 모노 선택 시 태그 칩·우선순위 막대·D-day 배지·캘린더
    요일색까지 **UI 전체가 회색조**로 렌더(우선순위는 농도·두께, D-day는 무채 농도 3단으로
    구분). **지남(overdue) 빨강만 위험 신호로 유지**.
  - 프리셋 9종은 배경·표면 수준에서 육안 구분되도록 색값 재점검(WCAG 대비 기준 포함),
    갤러리 썸네일이 배경/표면/강조/텍스트를 함께 미리 보여준다.
- **메인 창 — 사이드바형 (Things 스타일)** — 좌측 사이드바에 스마트 뷰 4개
  (**해야할 일 / 백로그 / 완료 / 캘린더**) + 태그 목록(태그 칩, 클릭 시 해당 태그로 필터).
  **사이드바 접기 (v4)**: 상단 **표준 macOS 사이드바 토글 하나(v5 — 중복 제거)**로
  사이드바를 접어 캘린더·리스트에 전폭 확보, 접힘 상태 저장·복원.
  - **해야할 일 (v4 개편)**: 섹션을 **① 지난 할 일 · ② 오늘 · ③ 예정** 3개로 축소해
    한 화면에서 쭉 스크롤. `🔴 지난 할 일`(미완료 overdue·이월 대상) → `오늘 M/d` →
    `예정`(내일 이후 전체, scheduled·due 통합). **예정**은 큰 섹션으로 쪼개지 않고
    하나의 연속 리스트로 묶되 내부에 **가벼운 미니 날짜 구분선**("내일 7/24", "7/28 (월)")으로 나눈다.
  - **미래 날짜 추가 (v4)**: 예정 리스트 상단 추가행 — 기본 날짜는 내일,
    `#태그 !우선순위 날짜` 토큰으로 임의 날짜 지정("기획서 7/28"). 내일 이후 추가 가능.
  - **날짜 간 이동 (v4)**: 리스트에서 task를 **다른 날짜 그룹으로 드래그 = scheduledDate 변경**
    (지난→오늘, 오늘→예정 특정일 등). 같은 그룹 내 드래그는 수동 정렬. 우클릭 오늘로/내일로/날짜 선택 병행.
  - **백로그**: 날짜 없는 항목. **완료**: 날짜별 그룹 히스토리(취소 항목 포함, 복구 가능).
  - 행: 체크박스 · 제목 · D-day 배지 · 이월 배지(↺n).
    **우선순위/태그 시각 구분 (v5)**: 우선순위는 행 왼쪽 **세로 색 막대**(높음=빨강 강조,
    보통=중립 얇은 회색, 낮음=흐림), 태그는 트레일링의 **글자 칩(TagPill)**(태그명 텍스트 +
    태그 색, 넘치면 "+N"). 둘 다 원(색 점)이던 방식을 폐기해 한눈에 구별된다.
    메인 행·오버레이·캘린더 일간/패널·상세 뷰가 공용 컴포넌트(PriorityBar/TagPill)로 통일.
    D-day 색: 지남=빨강, 오늘=주황, 임박(≤3일)=노랑, 여유=회색.
  - `AppTheme`(v5 — 동적 테마) 단일 디자인 시스템 — 팔레트에서 해석되는 색 +
    타이포 스케일·고대비 텍스트·호버 피드백·강조색.
- **캘린더 뷰 (v4 — 월/주/일)** — 상단 세그먼트로 **월 / 주 / 일** 전환(오늘·◀·▶는 현재 뷰 단위로 이동),
  선택 뷰 종류 저장·복원.
  - **주간 목표 노출 (v12)**: 기본 진입인 **월간** 뷰 헤더에도 이번 주(표시 중인 주가 현재
    주면 라이브, 아니면 그 주의 기록) **목표 진행 스트립**을 띄운다. 주간 뷰 헤더 칩은 진행
    n/m을 명확히 보이도록 강화. 스트립/칩을 클릭하면 사이드바 **「주간 목표」 뷰로 이동**.
  - **월간**: 셀 높이를 창 높이에 맞춰 키워 셀당 task 3~4개 + "+N개", overdue 빨강, 칩 호버 툴팁.
  - **주간**: 일~토 7열 세로 나열(스크롤), **열 간 드래그 = scheduledDate 변경**, 오늘 열 강조.
  - **일간**: 그날 하나를 전폭 리스트로, 제목 전체 표시.
  - **우측 날짜 패널 (v4)**: 본문·패널 경계 **드래그로 폭 조절**(저장·복원),
    항목 제목은 폭과 무관하게 **최대 2줄 줄바꿈**(넘치면 말줄임+툴팁). 날짜 클릭 → 그 날 목록 패널(체크/편집),
    "이 날 할 일 추가"는 패널 하단 별도 영역. task를 다른 날짜 셀로 드래그하면 scheduledDate 변경.
- **메뉴바 상주** — 아이콘 클릭으로 오늘 목록 요약 + 브리핑/오버레이/메인 창 열기.
  Dock 아이콘은 설정에서 토글. Dock 아이콘 클릭·앱 재실행 시 메인 창 표시.
- **플로팅 오버레이** — 오늘 할 일만 담은 작은 카드. 모든 Spaces·전체화면 앱 위에 표시,
  진행률 헤더, 자유 리사이즈(목록 스크롤).
  클릭 규칙: **체크 원 = 완료(1.5초 유예, 재클릭 취소) · 행/헤더 = 메인 창 열기**.
  창 이동은 헤더 드래그, 행 드래그는 수동 정렬.
  **크기 조절 (v12)**: 우하단에 **리사이즈 그립 어포던스**를 표시하고 가장자리 히트영역을 넓혀
  자유롭게 크기를 조절한다. **헤더 드래그는 절대 그랩점 기준(v12 버그 수정)** — 드래그 시작
  지점을 그대로 잡고 이동해 위치가 벌어지거나 밀리지 않는다.
  재시작·재부팅 후 표시 여부·위치·크기 복원.
- **브리핑 패널** — 오늘 할 일 + 어제(이전 논리적 하루) 미완료 목록.
  항목별/일괄로 「오늘로 가져오기(이월, ↺n 증가) / 백로그로 보류 / 버리기(취소 상태로 히스토리 보관)」 선택.
  드래그로 이동 + 위치 저장/복원. **크기 조절 (v12)**: 패널 자체를 리사이즈(min/max, 콘텐츠
  스크롤)할 수 있고 크기를 저장·복원한다. 하단 **이번 주 목표**는 진행 링과 함께 또렷하게
  보여주고 각 목표에 **[오늘 하기] 토글**을 두어 브리핑에서 바로 오늘에 배치/해제한다.
  자동 브리핑이 안 떴으면 **⌥⌘T**로 즉시 호출.
- **빠른 추가 (퀵애드 v2)** — 어디서든 Spotlight식 입력창. 토큰 문법은 아래 참고.
- **마감일 원클릭** — 날짜 UI마다 **[오늘] [내일] [최근 M/d]** 원클릭 칩.
  `lastUsedDueDate`를 기억해 연속 등록 시 직전 날짜를 딸깍 한 번으로 재사용,
  달력은 최근 설정한 날짜의 달로 열림.
- **완료 히스토리** — 완료는 삭제가 아니라 `completedAt` 기록. 완료 항목은 당일 리스트
  하단에 취소선으로 남고 다음 논리적 하루부터 숨김(사이드바 「완료」에서 조회).
  - **오늘로 복구 (v12)**: 「완료」의 **취소됨(및 완료) 행**에 **"오늘로 복구"** 액션 추가
    (되살리기 + `scheduledDate`=오늘). 기존 "되돌리기"(제자리 되살리기)는 그대로 두되,
    취소됨 행에는 과거 날짜로 되살아나 '지난 할 일'로 사라지지 않도록 "오늘로 복구"를 기본 노출.
    컨텍스트 메뉴와 상세 액션바 양쪽에서 일관되게 제공.
- **완료 유예 (v3)** — 체크하면 즉시 사라지지 않고 취소선으로 **1.5초 유지 후** 확정.
  유예 중 재클릭 = 완료 취소. 메인·오버레이·브리핑 공통.
- **반복 작업 (v3)** — 상세 뷰에서 **매일 / 평일 / 매주(요일 선택)** 설정, 행에 ↻ 배지.
  완료(또는 이월 제안에서 버리기) 시 다음 발생일 task 자동 생성
  (제목·태그·우선순위·규칙 승계, 서브태스크는 미완료로 복제).
- **정렬 통일 + 드래그 정렬 (v3)** — 초기 배치는 우선순위 높음 → 먼저 등록 순.
  이후 메인·오버레이에서 **행 드래그로 수동 정렬**(영속), 메인·오버레이·브리핑이 같은 순서.
- **재정렬 모션 (v4)** — 상하 재정렬 시 부자연스러운 점프를 없앤 **부드러운 스왑 애니메이션**과
  드래그 중 **삽입 위치 인디케이터**(얇은 액센트 선). 메인·오버레이 공통.
- **메인 인라인 추가 토큰 (v3)** — 메인 창 인라인 추가 행에서도 퀵애드와 같은
  토큰 문법(`#태그 !우선순위 날짜`) + 입력 중 칩 미리보기.
- **메인 창 상태 복원 (v3)** — 위치·크기·마지막 선택 사이드바 뷰를 재실행 시 복원.
- **메모 미리보기 (v8)** — 메모가 있는 task는 제목 아래 작은 보조 텍스트로 **메모 첫 줄**을
  한 줄 말줄임 표시(완료/유예 중엔 제목처럼 흐리게). 메인 리스트(해야할 일/백로그/완료)와
  브리핑 패널에만 적용 — 오버레이·캘린더 날짜 패널/일간 뷰는 밀도 유지를 위해 제외.
  설정 > 일반 「메모 미리보기 표시」 토글(기본 켬). 메모 없는 행의 높이는 불변.
- **포스트잇 스티키 노트 (v10)** — 투두와 별개의 자유 메모. 노트마다 독립 플로팅 카드 창
  (Stickies 스타일): 자유 이동·리사이즈, 위치·크기·색상 영속, 멀티라인 즉시 편집.
  상단 얇은 바에 **📌 핀 토글 · 색상 점 메뉴 · + 새 노트 · 닫기**.
  클래식 포스트잇 색 5종(노랑/핑크/민트/블루/라벤더) — 데이터 정체성이라 **모노 테마에서도
  유지**(무채 규칙 예외). 핀 끄면 일반 창 레벨(다른 앱 뒤로 감), 핀 켜면 그 노트만
  항상 위(전체화면 포함), 핀 상태 영속.
  - **보관함**: 노트 닫기 = 삭제가 아니라 **보관** — 사이드바 「포스트잇」 뷰에서
    열린 노트 + 보관 노트(닫은 날짜별 그룹)를 보고 **다시 열기 / 완전 삭제**.
  - **빈 노트 폐기 (v12)**: 내용이 공백뿐(trim 후 빈 문자열)이고 편집 이력이 없는 노트를
    닫으면 **보관하지 않고 폐기**(`stickies.json`에 남기지 않음). 내용이 있으면 기존대로 보관.
  - **다중 선택 삭제 (v12)**: 「포스트잇」 뷰(보관 목록)에서 **⌘/⇧클릭 다중 선택 + "선택 삭제"**
    (확인 후 완전 삭제). 열린 노트도 다중 선택 닫기/삭제.
  - 접근 경로: **⌥⌘S 새 포스트잇 · ⌥⌘H 전체 표시/숨김**, 메뉴바 팝오버 「새 포스트잇」 버튼.
    새 노트는 기존 노트 근처에 살짝 어긋나게 생성 + 즉시 입력 포커스.
- **주간 목표 (v11)** — **논리적 주**(기본 월요일 시작, 하루 기준 시각과 같은 규약 —
  주 시작 요일은 설정에서 변경) 단위의 목표. 제목·목표 횟수 n(**1=단일형 체크,
  2+=횟수형**)·**루틴(매주 반복)** 여부. 예: "헬스 3회"(횟수형·루틴), "책 1챕터"(단일형).
  - **일일 연계**: 목표의 **[오늘 하기]** → 연결 task를 오늘에 생성(행에 ↗주간 배지,
    이미 있으면 재사용). **[오늘 하기] 토글 (v12)**: 다시 누르면 해제 — 오늘의 미완료
    연결 task를 제거하고 (아직 카운트가 오르지 않았으므로) 목표 진행은 불변. 이미 완료된
    연결 task는 토글 대상이 아니라 카운트가 유지된다. 버튼은 **"오늘 있음/없음"** 상태를 반영.
    **연결 task 완료 확정(1.5초 유예 통과) 시 목표 +1**,
    완료 취소·되돌리기 시 -1. 목표에서 직접 ±1도 병행. 연결 task는 일반 task처럼
    이월·백로그·삭제 가능(삭제해도 이미 오른 카운트는 유지).
  - **노출 4곳**: 사이드바 「주간 목표」 뷰(추가/편집·진행 링·[오늘 하기]·직접 ±1·
    루틴 토글·**지난 주 기록** 주별 그룹+달성률) · 해야할 일 상단 **요약 카드**(접기
    가능, 접힘 영속) · 캘린더 주간 뷰 헤더 **그 주** 진행 스트립 · 브리핑 하단 미니 요약.

## 행 사용성 (메인 창)

클릭-펼침에 의존하지 않고 행에서 바로 처리한다:

- **호버 인라인 액션**: 행 우측에 날짜 / 우선순위 / 태그 / 삭제 아이콘
- **우클릭 컨텍스트 메뉴**: 상세 열기/닫기 / 이름 편집 / 오늘로 / 내일로 / 날짜 선택 /
  우선순위 / 태그 / 백로그로 / 삭제
- **더블클릭 제목 = 인라인 편집**. 상세 펼침(메모/서브태스크/마감일)은 유지

행을 클릭해 선택한 상태에서 쓰는 키보드 단축키:

| 키 | 동작 |
|---|---|
| ⌫ | 삭제 |
| Enter | 상세 펼침/접기 |
| ⌘1 / ⌘2 / ⌘3 | 우선순위 높음 / 보통 / 낮음 |
| ⌘T | 오늘로 이동 |
| ⌘D | 내일로 이동 |

## 퀵애드 토큰 문법 (⌥⌘N)

입력창에 제목과 토큰을 섞어 쓰면 실시간으로 파싱되어 입력창 아래 칩 행에 표시된다.
Enter 시 토큰이 제거된 제목으로 저장된다.

| 토큰 | 의미 |
|---|---|
| `#태그명` | 태그 지정. 입력 중 자동완성(부분일치), 없는 태그는 등록 시 생성 |
| `!높음` `!보통` `!낮음` (또는 `!1` `!2` `!3`) | 우선순위. 여러 개면 마지막이 이김 |
| `오늘` `내일` `모레` | 상대 날짜 (논리적 하루 기준) |
| `M/d` `M월 d일` `M월d일` | 절대 날짜 — 이미 지난 날짜면 내년으로 해석 |

- 칩 행: 파싱 결과를 실시간 표시, 칩 클릭으로 수정/제거 가능
- 빠른 버튼 행: **[오늘] [내일] [최근 M/d] [백로그]** — 날짜 토큰이 없을 때의 기본은 오늘,
  [백로그]를 누르면 날짜 없이 백로그로 등록 (날짜 토큰이 입력되면 토큰 우선)
- 예: `보고서 초안 #업무 !높음 내일` → 제목 "보고서 초안", 태그 업무, 높음, 내일

## 논리적 하루와 이월

이 앱의 하루는 자정이 아니라 **기준 시각(기본 09:00, 설정 가능)**에 시작한다.
새벽 2시에 작업 중이라면 아직 "어제"다.

앱 시작 / 잠자기 해제 / 기준 시각 도달 — 세 트리거에서 논리적 오늘이
마지막 브리핑 날짜보다 앞서 있으면 브리핑 패널이 하루 한 번 자동으로 뜬다.
패널에는 어제 미완료 작업이 함께 나오고, 각 항목을:

- **오늘로 가져오기** — `scheduledDate`를 오늘로, 이월 횟수 +1 (↺n 배지)
- **백로그로 보류** — 날짜 없는 백로그로 이동
- **버리기** — 삭제가 아니라 '취소됨' 상태로 히스토리에 보관 (복구 가능)

⌥⌘T로 부른 브리핑은 판단 없이 항상 표시된다.

**이월 카운트 정리 (v5)**: ↺n 배지는 **진짜 이월**(이전 예정일 미완료 → 브리핑
'오늘로 가져오기')에서만 오른다. **백로그로 보내는 모든 경로**(브리핑 보류·우클릭·
상세 뷰·행 날짜 팝오버)는 `rolloverCount`를 0으로 리셋한다 — 백로그는
'미룬 날'이 없으므로, 백로그에서 오늘로 다시 가져와도 ↺ 배지가 뜨지 않는다.
일반 재배정('오늘로'/'내일로'/드래그)은 카운트를 올리지 않는다.

**'지우기' 라벨 명확화 (v12)**: 행 날짜 팝오버의 날짜 지우기는 삭제가 아니라 백로그
이동이라, 라벨·아이콘을 동작에 맞게 구분한다 — `scheduledDate`를 비우는 곳(행)은
**"날짜 비우기 · 백로그"**(tray 아이콘·툴팁), 상세 뷰에서 마감일(`dueDate`)만 비우는 곳은
**"마감일 지우기"**로 분리해 삭제와 혼동되지 않게 했다(동작 자체는 종전과 동일).

## 빌드

### 1차 — SPM만으로 (Xcode 불필요, 위젯 제외)

```bash
git clone https://github.com/splguyjr/anham-die.git && cd anham-die
bash Scripts/build-app.sh --install   # → ~/Applications/AnhamDie.app
open ~/Applications/AnhamDie.app
```

`swift build -c release` → .app 번들 조립(LSUIElement, min macOS 15) →
ad-hoc 서명 → 설치. 외부 의존성은 KeyboardShortcuts 하나.

테스트: `swift test`

### 2차 — 위젯 빌드 (선택 — 기본 배포에서 제외됨)

위젯은 제외 결정(2026-07-24)되어 기본 빌드·brew 배포에 포함되지 않는다.
그래도 활성화하고 싶다면: 정식 Xcode와 코드서명(무료 개인 팀으로 충분)이 필요하다.

1. Xcode 설치 확인: `ls /Applications/Xcode.app` (App Store 설치 완료 여부)
2. `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer`
3. `sudo xcodebuild -license accept`
4. Xcode를 한 번 실행 → Settings > Accounts 에 Apple ID 추가 (무료 개인 팀).
   이후 `security find-identity -v -p codesigning`에 "Apple Development" 인증서가
   보여야 한다 (없으면 아무 타깃이나 자동 서명 한 번 돌리면 생성됨).
5. `bash Scripts/build-with-xcode.sh --install`
   (XcodeGen으로 앱+위젯 프로젝트 생성 → xcodebuild → 설치. `xcodegen`이 없으면
   `brew install xcodegen`)

빌드 후 반드시 확인할 것 (App Group 식별자 검증 — 미해결 이슈):

```bash
plutil -p ~/Applications/AnhamDie.app/Contents/Info.plist | grep AnhamDieAppGroupIdentifier
codesign -d --entitlements - ~/Applications/AnhamDie.app
```

두 값이 **완전히 일치**해야 한다 (양쪽 모두 `TEAMID.` 접두사 포함).
Info.plist 쪽에서 `$(TeamIdentifierPrefix)`가 빈 문자열로 확장되면 위젯·공유
저장소가 크래시 없이 조용히 무동작한다. 상세는 PLAN.md 구현 현황 참고.
